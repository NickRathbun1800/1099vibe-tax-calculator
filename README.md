# 1099Vibe Tax Calculator

Client-side 1099 tax estimator. Next.js 15 + React 19 + Tailwind 4, exported as
static HTML (`output: "export"`). No server, no database, no API keys.

## Local development

    npm install
    npm run dev      # http://localhost:3000
    npm run build    # static site written to ./out

## Deploy

Vercel auto-detects Next.js. No build settings or environment variables needed.
